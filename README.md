# gel-nail-polish

אפליקציית תורים ללק ג׳ל — PWA בעברית (RTL). לקוחות קובעות תור לבד; בעלת העסק מנהלת יומן, שעות ומחירון.

## מה יש כאן

| תיקייה | תוכן |
|---|---|
| `public/` | האפליקציה עצמה (HTML, CSS, JavaScript רגיל, בלי שלב בנייה) |
| `api/` | שלוש פונקציות שרת ל-Vercel: `config`, `login` (כניסה בקוד חד-פעמי), `dispatch` (שליחת וואטסאפ ופוש) |
| `supabase/migrations/` | מבנה המסד וכל הלוגיקה: זמינות, קביעה, ביטול, הרשאות, תזכורות |
| `tests/` | 46 בדיקות אוטומטיות למנוע התורים, מול Postgres אמיתי שרץ מקומית |
| `scripts/` | שרת פיתוח מקומי והעתקת קבצים חיצוניים ל-`public/vendor` |

## הרצה ובדיקה

```bash
npm ci          # התקנה
npm test        # בדיקות המנוע (שער A בתוכנית) — לא נוגעות במסד האמיתי
npm run dev     # האפליקציה ב-http://localhost:3000, מול המסד שמוגדר ב-.env.local
```

`.env.local` (לא נשמר ב-git):

```
SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_ANON_KEY=<המפתח הציבורי>
SERVER_SECRET=<אותו ערך כמו dispatch_secret בטבלה private.app_config>
DEMO_LOGIN=1
```

## איך זה בנוי

- **המסד הוא מקור האמת.** קביעת תור עוברת רק דרך `book_appointment`; אילוץ `EXCLUDE` במסד מונע כפל תורים
  גם אם עוקפים את הפונקציה. לקוחה רואה רק את התורים שלה (RLS), ופונקציית הזמינות מחזירה שעות בלבד.
- **כל החישובים בשעון `Asia/Jerusalem`**, כולל מעבר לשעון קיץ.
- **השרת לא מחזיק מפתח-על.** הוא פונה למסד עם המפתח הציבורי ועם סוד משותף (`SERVER_SECRET`),
  ורק פונקציות `srv_*` במסד מקבלות אותו.
- **סודות והגדרות שרת** (מפתחות פוש, פרטי וואטסאפ, קוד ההקמה של בעלת העסק) שמורים בטבלה `private.app_config`,
  שאינה נגישה דרך ה-API.

## מצב בדיקה (`DEMO_LOGIN=1`)

כל עוד וואטסאפ לא מחובר, קוד הכניסה מוצג על המסך במקום להישלח. **זה אומר שכל אחד יכול להיכנס בשם כל מספר טלפון.**
חובה לכבות (`DEMO_LOGIN=0`) לפני שעולים עם לקוחות אמיתיים.

## חיבור וואטסאפ (כשיהיה אישור מ-Meta)

מוסיפים שורות ל-`private.app_config`: `wa_token`, `wa_phone_number_id`, ושמות התבניות
`wa_tpl_code` (קוד כניסה), `wa_tpl_confirm` (אישור קביעה), `wa_tpl_reminder` (תזכורת).
סדר המשתנים בתבניות האישור והתזכורת: `{{1}}` שם, `{{2}}` טיפולים, `{{3}}` יום, `{{4}}` תאריך, `{{5}}` שעה.
כדי שהמסד "יעיר" את פונקציית השליחה צריך גם `dispatch_url` = `https://<הדומיין>/api/dispatch`.

## רישום בעלת העסק

בעלת העסק נכנסת עם הטלפון שלה, פותחת `/#/setup` ומזינה את קוד ההקמה (`owner_claim_code`). הקוד חד-פעמי ונמחק אחרי השימוש.
